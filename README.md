# 外送派單判斷（三重蘆洲）

iPhone 捷徑擷取派單畫面 → 本機 OCR → 送文字到這支 API → 語音唸出「接／看情況／不接，時薪多少，落點哪裡」。

不會自動接單，最後由你自己按。不儲存任何截圖或文字。

> ⚠️ 派單畫面的文字格式目前是假設的，還沒用真實截圖驗證。拿到真實 OCR 文字後，主要要改 `lib/parse.js` 的正規表示式。

## 檔案

| 檔案 | 用途 | 常改嗎 |
|---|---|---|
| `lib/config.js` | 目標時薪、每公里成本、疊單保底倍數 | 常改 |
| `lib/zones.js` | 三重蘆洲落點分級表（路名 → 熱區／空車分鐘） | 常改 |
| `lib/parse.js` | 解析 OCR 文字（金額、分鐘、公里、單量、落點） | 拿到真實樣本後改 |
| `lib/judge.js` | 計算實際時薪與判斷 | 少改 |
| `api/judge.js` | Vercel API 進入點 | 少改 |

## 計算方式

```
保底     = 分鐘 × 245 ÷ 60（疊單可乘 stackFloorMultiplier）
實際拿到 = max(畫面金額, 保底)
淨收入   = 實際拿到 − 公里 × 每公里成本
實際時薪 = 淨收入 ÷ (分鐘 + 落點空車分鐘) × 60

≥ 目標時薪            → 接
≥ 目標時薪 × 0.8      → 看情況
其他                  → 不接
```

## 部署到 Vercel

```bash
npm i -g vercel
vercel            # 第一次會問專案名稱
vercel env add JUDGE_TOKEN   # 設一組自己的金鑰，避免別人亂打
vercel --prod
```

部署後的網址：`https://<專案名>.vercel.app/api/judge`

## iPhone 捷徑設定

在「捷徑」App 新增一個捷徑，依序加入以下動作：

1. **擷取螢幕畫面**
2. **從影像擷取文字**（輸入：螢幕截圖）
3. **取得 URL 內容**
   - URL：`https://<專案名>.vercel.app/api/judge`
   - 方法：POST
   - 標頭：`x-judge-token` = 你設的金鑰
   - 要求內文：JSON
     - `text`（文字）= 「從影像擷取的文字」
     - `target`（數字）= 200（你的目標時薪，可省略）
4. **取得字典值**：取得「speak」的值（輸入：URL 的內容）
5. **說出文字**（輸入：字典值）

選用：在第 3 步前加「如果 沒有網路」，改成本機只唸保底金額（分鐘 × 4.08）。
